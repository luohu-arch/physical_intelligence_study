# Human-as-Humanoid: Enabling Zero-Shot Humanoid Learning from Ego-Exo Human Videos

- 本地 PDF：`papers/vla-architecture/Human-as-Humanoid_2606.32009.pdf`
- arXiv：https://arxiv.org/abs/2606.32009
- 年份：2026（6 月, CoRL 2026）
- 团队：HKUST(GZ), DeepCybo 等
- 阶段：硬件-软件联合设计 —— 人类视频零样本→人形动作

## 一句话总结

Human-as-Humanoid 提出硬件-软件联合设计：设计 PrimeU 人形使其身体比例对齐人类，配合 ego-exo 双视角视频→60-DoF 动作 pipeline，实现零样本迁移——无需任何机器人演示数据。CoRL 2026。

## 核心技术

1. **PrimeU 硬件** — 肩宽比 0.97, 臂长比 1.02, 手长比 1.00 人类对齐人形
2. **Ego-Exo Pipeline** — ~20 FPS: 外视角跟踪→mesh 重建→分阶段 IK 重映射→60-DoF action
3. **DS-HKC Loss** — FK-aware dual-space 监督（关节空间 + 任务空间）
4. **4.8-7.2× throughput** over 传统动捕遥操作

## 底层原理与数学推导

分阶段 IK: 先求解臂部 7-DoF IK 使腕部位姿匹配人类腕部，再求解手部 20-DoF IK 使指尖位置匹配。DS-HKC loss 同时约束关节角度和末端位姿。

**1. 分阶段 IK 重映射**：Stage 1 求解臂部 7-DoF IK，使机器人腕部位姿 $T_{wrist}^{robot}$ 对齐人类腕部 $T_{wrist}^{human}$；Stage 2 固定腕部后求解手部 20-DoF IK，使指尖位置 $p_{tip}^{robot}$ 匹配 $p_{tip}^{human}$。分阶段求解避免高维 IK 的奇异性与局部最优，输出控制器对齐的 60-DoF 动作块。

**2. DS-HKC 双空间损失**：人形高维动作存在"空间错配"——策略输出的是关节指令，但操作成败取决于腕部运动、指尖位置与接触几何。DS-HKC 通过可微前向运动学 $FK(q)$ 在任务空间补充监督：

$$
\mathcal{L} = \underbrace{\|q_{pred} - q_{demo}\|_2^2}_{\text{关节空间}} + \lambda \underbrace{\left( \|FK_{wrist}(q_{pred}) - T_{wrist}^*\|_2^2 + \|FK_{tip}(q_{pred}) - p_{tip}^*\|_2^2 \right)}_{\text{任务空间（FK 监督）}}
$$

**3. 硬件-感知-接口对齐**：PrimeU 肩宽比 0.97、臂长比 1.02、手长比 1.00 人类对齐；头戴 + 腕部 RealSense D435 提供与部署一致的 ego 观测；转换管线约 20 FPS，在 15 Hz 采集设定下较动捕遥操作获得 4.8–7.2× 原始示教吞吐增益。

## 物理直觉解释

**Human-as-Humanoid 的核心洞察：把"翻译问题"变成"几何问题"**。将人类动作迁移到人形机器人，传统思路是让 AI 学习两个身体之间的映射（embodiment gap），但 Human-as-Humanoid 反其道而行：把机器人的肩宽比做到 0.97、臂长比 1.02、手长比 1.00——身体比例与人类几乎一致。就像两个人身高臂展相同，一个人的投篮动作几乎可以直接照搬给另一个人；比例对齐后，人类动作到机器人关节角的转换退化为纯运动学 IK 求解，不再需要大规模学习。

**Ego-Exo 双视角像"第一人称 + 无人机跟拍"的组合**：腕部/头部 ego 视角提供与部署一致的观测（机器人执行时看到的东西和人类演示时看到的一致），外视角负责在遮挡下稳定恢复全身动作。这解决了单视角的致命弱点——手部自遮挡。数据采集侧，pipeline 以 ~20 FPS 实时运行，在 15 Hz 采集设定下比动捕遥操作快 4.8–7.2 倍：采集人类视频的成本是拍视频，而采集机器人动捕数据的成本是穿动捕服 + 逐帧人工对齐。

**DS-HKC 双空间损失像"既要动作像，又要结果对"**：只约束关节角度的策略可能"动作模仿到位但手却没碰到目标"——关节空间离操作成败太远。DS-HKC 通过可微 FK 把预测的 60-DoF 关节序列投影到腕部位姿与指尖位置，与人类演示的末端几何直接比对。这相当于教练既看你的姿势（关节角）又看球进没进（末端位置），两个层面同时纠错，是"零目标任务机器人演示即可部署"的关键训练配方。

- PrimeU: 双臂 7-DoF + 双灵巧手 20-DoF + 颈 3-DoF + 腰 3-DoF
- 传感: 头戴+腕部 RealSense D435
- Pipeline: 外视角人体跟踪→mesh-aware 重建→staged IK→60-DoF chunks
- 测试任务: 戒指放置、魔方装箱、倒水、叠杯、拧瓶盖

## 消融实验与分析

| 消融 | 设置对比 | 关键指标 |
|------|---------|---------|
| 数据采集范式 | 人类视频转换 vs 动捕遥操作（15 Hz 采集设定） | 4.8–7.2× 原始示教吞吐增益 |
| 实时性 | 转换管线运行速率 | ~20 FPS（接近常见 15 Hz 采集率） |
| 观测-运动兼容性 | ego-exo 纯相机恢复 vs 动捕服关键点 | 相机恢复的关键点更稳定 |
| Ego-Exo vs 仅 Exo | 双视角 vs 单外视角 | 双视角对精细手部操作（自遮挡下）必要 |
| Staged IK vs 统一 IK | 分阶段（臂 7-DoF → 手 20-DoF）vs 整体求解 | 分阶段求解稳定性和精度均更优 |
| DS-HKC vs 仅关节空间 | 双空间 vs 仅关节角度 | 任务空间（FK）约束对末端精度关键 |
| 部署验证 | 仅用转换的人类标签训练 | 戒指放置/魔方装箱/倒水/拧瓶盖等零目标任务机器人演示即部署 |

**核心结论**：这条"硬件-感知-接口"对齐链路的每一环都可独立消融——身体比例对齐（0.97/1.02/1.00）把迁移难度从学习问题降为 IK 求解；ego-exo 双视角提供稳定的人体关键点恢复（相机方案甚至优于动捕服）；分阶段 IK 避免高维整体求解的不稳定；DS-HKC 的 FK 任务空间监督弥补"关节像 ≠ 结果对"的错配。四者叠加使 60-DoF 人形在无任何目标任务机器人演示的情况下，仅凭人类视频转换标签完成真实部署，吞吐增益 4.8–7.2× 则回答了"为什么值得这么做"的工程问题。

## 技术权衡

| 优势 | 劣势 |
|------|------|
| 零样本，无需机器人 demo | 依赖定制硬件 PrimeU，比例对齐要求限制了通用人形复用 |
| 4.8–7.2× throughput over 动捕 | 仅覆盖上身（60-DoF），不含腿部 locomotion |
| 相机-only 恢复，无需动捕服 | 手部自遮挡严重时仍需 ego 视角辅助，复杂背景鲁棒性待验证 |

## 技术价值与演进定位

核心洞察：**硬件对齐可以大幅降低 AI 负担**。和 HumanPlus (Stanford, 2024) 形成互补——Human-as-Humanoid 用硬件-软件联合设计（让身体比例与传感配置匹配人类），HumanPlus 用 RL 弥合 embodiment gap。这一思路对"数据采集成本"这一人形机器人最大瓶颈给出了系统性答案：把采集对象从"机器人"换成"人"，吞吐提升近一个数量级；同时证明了人类视频这一近乎无限的数据源可以直接驱动高自由度人形策略训练，为后续大规模"人类数据 → 人形技能"路线（Ego4D 级数据 + 人形本体）提供了完整可复现的转换链。

## 与其他论文的关系

- **HumanPlus (Stanford 2024)** — 人类视频→人形：HumanPlus 用 RL 学习 embodiment gap 映射，Human-as-Humanoid 用硬件对齐 + 运动学求解，两条路线互为镜像
- **ROVE (XPeng 2026)** — 人形 VLA 后训练：ROVE 用价值过滤处理遥操作干预噪声，本工作解决的是更上游的"高质量人类标签生成"
- **PhysDex / PhysBrain** — 本工作的 VLM backbone 沿用 PhysBrain 等 manipulation-aware 模型，属"观察-动作兼容"的既有基础设施
- **Ego4D / 大规模人类视频系** — 本工作把人形数据采集从遥操作转向 ego-exo 人类视频，正是 Ego4D 式数据在机器人上的落地通道

## 精读问题

1. 身体比例不对齐时 pipeline 哪一步最先崩？对齐误差（如臂长比偏离 1.0）与 IK 精度之间的量化关系？
2. Ego-exo 双视角 vs 单视角的精度差异量化？自遮挡最严重的手部动作（如拧瓶盖）在单视角下的失败率？
3. 分阶段 IK 的两阶段误差如何传递？腕部 7-DoF 的位姿误差对手部 20-DoF 求解的解空间影响？
4. DS-HKC 中任务空间权重 λ 的选择依据？FK 监督与关节监督冲突（奇异位形附近）时如何权衡？
5. 60-DoF 上身 + 无腿部的设定——若扩展全身（含 locomotion），比例对齐假设还成立吗？行走动作能否沿用同一 pipeline？
6. 转换标签训练的策略在"新场景、新物体"上的泛化——人类视频的多样性是否直接转化为策略的开放世界能力？
