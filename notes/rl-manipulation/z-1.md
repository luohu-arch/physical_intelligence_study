# Z-1: Efficient RL Post-Training for VLA Models

- 本地 PDF：`papers/rl-manipulation/Z-1_2605.00345.pdf`

- arXiv：https://arxiv.org/abs/2605.00345
- 年份：2026
- 阶段：模块化 VLA RL 后训练 — 仅用公开 RoboCasa 数据 SFT + per-scene RL 精调

## 一句话总结

Z-1 提出基于 π0.5 的模块化 RL 后训练框架：仅用公开 RoboCasa 演示数据做 SFT，然后 per-scene RL 精调。不需要专有数据即可将开源 VLA 提升到竞赛水平。

## 核心技术

1. 模块化 design——freeze VLA backbone, train lightweight RL modules
2. 仅用公开数据 SFT + per-scene online RL 精调
3. 比 full fine-tune 更高效且不会 overwrite pretrained knowledge

## 技术价值

RL 后训练正在成为 VLA 的标准步骤——Z-1 证明即使是开源 VLA + 公开数据也能通过 RL 显著提升。
