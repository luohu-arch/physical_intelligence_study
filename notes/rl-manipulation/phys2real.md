# Phys2Real: VLM Priors + Uncertainty-Aware Sim2Real

- 本地 PDF：`papers/rl-manipulation/Phys2Real_2602.09485.pdf`

- arXiv：https://arxiv.org/abs/2602.09485
- 年份：2026 (ICRA 2026)
- 团队：Stanford MSL
- 阶段：VLM 估计物理参数 → RL 策略条件化 → 在线适应

## 一句话总结

Phys2Real 提出 Real-to-Sim-to-Real 三阶段管道：VLM 从真实图像估计物理参数（如质心 CoM），RL 策略以物理参数为条件训练，部署时不确定性感知融合 VLM 先验与交互式在线适应。

## 核心技术

1. VLM 从 RGB 估计物体物理参数（质量、质心、摩擦）
2. 策略以物理参数为条件 → sim 中训练条件化策略
3. 部署时 Bayesian 融合 VLM prior + 在线交互观测

## 技术价值

VLM 开始深入物理推理——不只是"这是什么"，而是"这个东西有多重、重心在哪"。
